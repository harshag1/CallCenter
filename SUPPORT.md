# Support

Use GitHub Discussions or an issue for reproducible setup questions, provider adapter problems, flow behavior, and benchmark tooling. Search existing reports first.

Include:

- the exact commit and operating system;
- Node.js version and package manager version;
- the command that failed;
- a minimal redacted configuration;
- expected and observed behavior; and
- relevant stable error codes or sanitized logs.

Never include API keys, `.env` contents, caller audio, transcripts, phone numbers, email addresses, database URLs, authorization headers, raw provider events, or private benchmark artifacts.

This is an open-source framework, not a hosted emergency, compliance, or production support service. Do not rely on maintainers for urgent calling, medical, legal, safety, or incident-response operations.

Security vulnerabilities belong in the private process in [SECURITY.md](SECURITY.md), not a public issue. Evidence or research claims belong in the benchmark protocol and must respect its evidence classes.
