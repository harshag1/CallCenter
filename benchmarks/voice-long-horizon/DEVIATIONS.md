# Protocol deviations

<!-- markdownlint-disable MD013 MD060 -->

- Protocol: `HACC-LHVR-v0.1`
- Protocol status: draft, not frozen
- Confirmatory deviations: **none**

Before freeze, substantive design changes are recorded in [PROGRESS.md](PROGRESS.md) and incorporated into the next protocol version. After freeze, this file becomes append-only. Every entry must include:

- Pacific timestamp and author;
- frozen field and original value;
- changed value or operational action;
- reason known before comparative outcomes were inspected;
- affected run IDs, conditions, providers, and scenarios;
- whether operators were unblinded;
- effect on inclusion, analysis, spend, and allowed claims;
- source commit and evidence links.

Reserve use under [BUDGET.md](BUDGET.md) also requires an entry here before a new session is scheduled. A deviation never erases the original run or frozen protocol value.
